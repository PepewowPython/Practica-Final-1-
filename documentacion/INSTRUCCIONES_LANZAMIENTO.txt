📋 REQUISITOS PREVIOS
================================================================================
- Node.js v18.0.0 (o superior)
- npm (incluido con Node.js)
- Navegador web moderno (Chrome, Firefox, Safari, Edge)
- Terminal / Consola

🚀 PASOS PARA LANZAR LA APLICACIÓN
================================================================================

OPCIÓN A: Lanzamiento Simultáneo Concurrente (RECOMENDADA)
--------------------------------------------------
1. Abre una terminal en la raíz del proyecto y ejecuta:
    npm run install:all

2. Para iniciar Backend (puerto 5000) y Frontend (puerto 5173) al tiempo:
    npm run dev


OPCIÓN B: Lanzamiento en Terminales Separadas
--------------------------------------------------
PASO 1: Instalar dependencias
    npm install

PASO 2: Iniciar Servidor Backend (Terminal 1)
    npm run server
    -> Esperado: "Backend server running on http://localhost:5000"

PASO 3: Iniciar Servidor Frontend (Terminal 2)
    npm run dev:frontend
    -> Esperado: "VITE ready on http://localhost:5173/"

PASO 4: Abrir la Aplicación
    Navega a: http://localhost:5173/

✨ CARACTERÍSTICAS Y MÓDULOS DE LA PLATAFORMA
================================================================================

🗺️  MAPA INTERACTIVO Y CALCULADORA DE RUTAS SEGURAS
   - Visualización georreferenciada de incidentes (Rojo: Alto, Amarillo: Medio).
   - Motor de ruteo OSRM con evasión de zonas de riesgo y factor de tráfico dinámico.

📢 REPORTE CIUDADANO DE INCIDENTES
   - Formulario geolocalizado en el mapa (Hurto, Iluminación, Sospechoso).
   - Registro en estado "pendiente" para auditoría por moderadores.

🛡️ PANEL DE MODERACIÓN DE SEGURIDAD
   - Bandeja de incidentes reportados por los ciudadanos.
   - Herramientas de edición, filtro por estado y aprobación/rechazo en tiempo real.

📊 CENTRO DE ANALÍTICA E INTELIGENCIA
   - Métricas agregadas por tipología y franja horaria.
   - Ranking de cuadrantes críticos y exportación de informes en CSV.

⚙️ ADMINISTRACIÓN RBAC Y USUARIOS
   - Asignación dinámica de roles y control de estado (activo/suspendido).
